# Peris Mutena | Personal Portfolio

A professional, responsive, and classic personal portfolio website built for **Peris Mutena**, a Psychology Student & Mental Health Advocate.

## 🎨 Theme & Design
- **Primary Palette:** Warm brown tones, cream, and soft beige.
- **Style:** Classic, clean, minimal, and elegant.
- **Typography:** Professional Serif (Playfair Display) for headings and Sans-Serif (Montserrat) for body text.

## ✨ Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Smooth Navigation:** Seamless scrolling between sections.
- **Scroll Reveal Animations:** Subtle fade-in effects as you browse.
- **Contact Form:** Integrated with **Formspree** for real-time email submissions.
- **Semantic HTML5:** Clean and SEO-friendly structure.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript

## 🚀 Getting Started
1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser.
3. To customize the contact form, update the `action` attribute in the form tag within `index.html` with your own Formspree ID.

## 📝 Contact Form Setup
The website uses [Formspree](https://formspree.io/) to handle contact form submissions. 
- The current endpoint is configured for `teshperis8@gmail.com`.
- **Note:** Upon the first submission, you will receive an email from Formspree to activate the form.
